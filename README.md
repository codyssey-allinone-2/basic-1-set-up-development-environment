## 프로젝트 개요
리눅스 CLI, Docker, Git 사용법을 익히는 실습이다.

## 프로젝트 구성
- docker : docker-compose 실행 파일
- report: 실습 결과 기록
- resource: 실습 결과 기록에서 사용하는 이미지(스크린샷) 

### 실행환경
OS: macOs Ventura
Shell: Zsh
Docker: 28.1.1
GIT: 2.55
